Figure sources

Every figure in the ML chapters is an original plot made for these notes; no external artwork or course slides are reproduced. All figures are drawn with D3 and typeset with KaTeX in the style of the Foundations figures, then rendered to PNG at twice their CSS size by headless Chromium. The figures of chapter 1 were redrawn on 27 September 2026 and those of chapters 2 to 17 on 28 September 2026, replacing Matplotlib versions; a redrawn figure keeps the data, seeds, and fitted models of the version it replaces unless its row says otherwise. The source of each figure is Sources/Figure code/js/src/<name>.js. Figures that show a fitted model, such as a scikit-learn estimator, an EM run, or a Gaussian-process fit, read their numbers from js/data/<name>.js, which the chapter’s script in Sources/Figure code writes; the other figures compute their data in JavaScript, drawing random numbers from the seeded generator of the Foundations figure code. Each chapter script, from ch01_nearest_neighbors.py to ch17_smoothing.py, also recomputes and prints every number that its chapter and captions quote from the figures. The tables below summarize the data, seeds, and model settings of each figure so that it can be read and regenerated without opening the code; the computing setup gives the environment and commands.

In the Python scripts, seeds refer to numpy.random.default_rng(seed) unless a scikit-learn random_state is named; makeRng(seed) is the linear congruential generator of the Foundations figure code, which the scripts port to Python where they recompute a JavaScript simulation. Simulated results are single illustrative runs or averages over the stated number of repetitions; they illustrate the claims in the notes but do not replace the stated assumptions of the theorems.

1. Learning problems and nearest neighbors {#1-learning-problems-and-nearest-neighbors}

Each figure is drawn from the stated model with D3 and typeset with KaTeX, then rendered to PNG at twice its CSS size by headless Chromium, using the drawing library of the Foundations figures. The source of each is Sources/Figure code/js/src/<name>.js, and the computing setup gives the commands. Random draws use the seeded linear congruential generator of the Foundations figure code, so every figure is reproducible exactly. The script ch01_nearest_neighbors.py recomputes, independently of the drawing code and with the same generator, every number that the chapter and its captions quote from these figures, and the table of asymptotic \(k\)-NN errors in Appendix A.

The classification figures share one model: two equally likely Gaussian classes, \(\mathcal N\bigl((0,0),\operatorname{diag}(1,4)\bigr)\) for class 0 and \(\mathcal N\bigl((2,0),\operatorname{diag}(1,1/4)\bigr)\) for class 1, whose Bayes boundary is the parabola \(x_1=1-\ln2+\tfrac{15}{16}x_2^2\) and whose Bayes error is \(0.099\). Training samples are drawn with the seeded generator of the figure code. The population error of a fitted rule is its conditional error, \(\eta\) or \(1-\eta\), weighted by the density of \(X\) and summed over a regular grid on \([-5.5,7]\times[-9,9]\), which holds all but a negligible fraction of the probability; it is therefore exact up to the grid resolution rather than estimated from a test sample.

2. The perceptron and linear separation {#2-the-perceptron-and-linear-separation}

Each figure is drawn with D3 and typeset with KaTeX, then rendered to PNG at twice its CSS size by headless Chromium, using the drawing library of the Foundations figures. The source of each is Sources/Figure code/js/src/<name>.js, and the computing setup gives the commands. Every figure computes its own data in JavaScript, so there are no data files; random draws use the seeded linear congruential generator of the Foundations figure code, so every figure is reproducible exactly. The script ch02_perceptron.py recomputes, independently of the drawing code and with the same generator, every number that the chapter and its captions quote from these figures; it runs in about ten seconds.

Separable samples share one construction. A random unit vector \(u\) is drawn first (\(d\) standard normals, normalized). Each point is then a uniformly random direction, a normalized vector of \(d\) standard normals, scaled by \(U^{1/d}\) with \(U\) uniform, so that it is uniform in the unit ball; it is labeled by the sign of \(u^\top x\) and pushed along \(u\), away from the hyperplane \(u^\top x=0\), until its margin along \(u\) is at least \(\gamma\). \(R\) is the largest norm in the sample and \(\gamma\) the realized margin \(\min_iy_iu^\top x_i\) along \(u\). The perceptron is homogeneous, starts from \(w_1=0\), counts a zero score as a mistake, visits the points in a fresh random order in each pass (a Fisher–Yates shuffle driven by the seeded generator), and stops after a pass without mistakes.
