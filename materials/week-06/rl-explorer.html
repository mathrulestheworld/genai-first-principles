1Gridworlds: play them, then watch an algorithm learn

Play first: you are the policy and choose every move, and the world decides where the move really goes and what it pays. Then watch an algorithm learn the same world. Value iteration knows the world's rules and sweeps the Bellman optimality update over every cell. Q-learning, SARSA, and Monte Carlo control know nothing; they walk the grid, acting ε-greedily, and learn action values from what happens: Q-learning and SARSA after every step, from the reward and their own next estimate, Monte Carlo after each episode, from the return that followed.

2Predicting values: Monte Carlo against TD

Both estimate the values of one fixed policy in the short corridor (section 4) from the same episodes. Monte Carlo waits for each episode to end and moves each visited state's value toward the return that followed; TD moves it after every step toward one reward plus its own estimate of the next state. Every step costs 1, so a state's true value is minus the expected number of steps to the goal.

3Bandits: why an agent must explore

A bandit is a one-step problem: pull an arm, get a reward drawn from that arm's distribution, repeat. The agent learns only about the arms it pulls, so it must trade exploiting the best arm so far against exploring the others. Set the arms, pull them yourself, then run the rules on the same arms. The page opens on the notes' bandit: two arms that pay 1 with probabilities 0.7 and 0.4, and 0 otherwise. A short horizon flatters ε-greedy, so watch the regret curves bend.

4The policy gradient on a short corridor

Three states and a goal; every step costs 1. The agent cannot tell the states apart, so its policy is one number, p, the chance of moving right, and in the middle state the actions are reversed. The best p is 2 − √2 ≈ 0.586. REINFORCE weights each action by the return that followed it; a baseline subtracts a learned average return; actor–critic weights it by a critic's TD error.

5PPO's clipped objective

PPO reuses a batch for several steps by weighting each sample's advantage Â by the ratio ρ = πnew(a|s) / πold(a|s). The surrogate ρÂ is right near the old policy and wrong far from it; PPO takes the smaller of ρÂ and clip(ρ, 1 − ε, 1 + ε)Â, so a sample stops asking for change once its ratio has moved by ε in the direction its advantage favors.

6Behavior cloning and DAgger

An expert crosses a 7 × 7 grid past four pits; whoever acts, a move is replaced by a random one with probability 0.15. The learner copies the expert's action in each state it has a label for, and moves at random elsewhere. Cloning takes its labels from the expert's own episodes; DAgger takes half from them and half by running the learner and asking the expert what it would have done where the learner went.
